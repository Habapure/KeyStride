# KeyStride / 键步如飞
> [English](#english) | [中文](#中文)

## English

A Windows utility that pastes clipboard text into any input field.
Three typing modes (human, fast, instant), system tray operation, default hotkey `Ctrl+Shift+V`.

### Installation
```powershell
pip install -r requirements.txt
python main.py
```

### Build
```powershell
python build.py
```

### Usage
- `Ctrl+Shift+V` to start.
- `Esc` to cancel.
- Change mode/hotkey via tray menu.

## 中文

Windows自动化打字工具，自动粘贴剪贴板内容到任意输入框。
支持三种输入模式、系统托盘运行，默认热键 `Ctrl+Shift+V`。

### 安装
```powershell
pip install -r requirements.txt
python main.py
```

### 打包
```powershell
python build.py
```

### 使用
- 按 `Ctrl+Shift+V` 开始输入。
- 按 `Esc` 取消。
- 托盘菜单可以调整模式和热键。
